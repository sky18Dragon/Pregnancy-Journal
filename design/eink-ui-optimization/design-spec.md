# reTerminal Sticky 中文墨水屏视觉规范

## 1. 画布与安全区

| 项目 | 规格 |
| --- | --- |
| 画布 | 800 × 480px，横屏 |
| 安全区 | 左右 32px，上下 24px |
| 内容宽度 | 736px |
| 基础栅格 | 8px |
| 常用间距 | 8 / 16 / 24 / 32 / 40px |

页面不做响应式缩放。原型浏览器视图和后续固件渲染都以 800 × 480 为唯一目标尺寸。

## 2. 字体与字重

字体风格：优先采用 `Noto Sans SC / Source Han Sans SC / 思源黑体`；原型使用系统中最接近的 `Hiragino Sans GB / PingFang SC` 回退链。

| 层级 | 字号 | 字重 | 行高 | 用途 |
| --- | ---: | ---: | ---: | --- |
| 页面标题 | 30px | 500 Medium | 40px | 孕期手帐、功能 |
| 模块标题 | 24px | 500 Medium | 32px | 宝宝这周、产检 |
| 正文 | 17px | 400 Regular | 26px | 发育与身体变化说明 |
| 功能说明 | 16px | 400 Regular | 24px | 功能入口描述 |
| 辅助标签 | 15px | 400 Regular | 22px | 模块标签、底部说明 |
| 功能编号 | 40px | 500 Medium | 48px | 01–06 |
| 孕周数字 | 62px | 500 Medium | 64px | 20 |
| 数字单位 | 18px | 400 Regular | 24px | 周、电量百分比 |

排版细节：

- 正文视觉字距为 0.5px；辅助文字为 0.4px。
- 中文标题字距保持 0，不使用负字距。
- 正文不使用 Bold 或 SemiBold。
- 动态数字使用等宽数字特性，避免数值变化时左右跳动。
- 后续字体点阵生成应优先优化 15、16、17、24、30、40、62px 七个目标尺寸。

## 3. 四级灰度

| Token | 原型颜色 | 设备目标级 | 用途 |
| --- | --- | --- | --- |
| `--ink-primary` | `#202020` | 黑（0） | 页面标题、模块标题、关键数字 |
| `--ink-secondary` | `#5B5B5B` | 深灰（85） | 正文、说明、箭头、电量文字 |
| `--ink-divider` | `#AAAAAA` | 浅灰（170） | 分割线、按钮边框、电池轮廓 |
| `--paper` | `#F4F4F2` | 白（255） | 页面背景 |

不使用灰度渐变、透明阴影或抗锯齿产生的额外灰阶。固件实现时将设计 Token 映射到现有四阶像素值。

## 4. 线条与边框

- 所有分割线为 1px、浅灰。
- 首页只保留顶部边界、左右结构边界和右栏模块必要分隔。
- 功能列表最后一行不绘制底线，避免形成完整表格边框。
- 关闭按钮为 1px 浅灰描边、无圆角、无填充。
- 菜单按钮为 44 × 44px，图形线宽 1px，触控区域与视觉区域一致。

## 5. 孕期首页布局

| 区域 | 位置与尺寸 |
| --- | --- |
| 顶栏 | x=32，y=24，w=736，h=56 |
| 主内容 | x=32，y=96，w=736，h=304 |
| 左栏 | w=304 |
| 栏间距 | 32px |
| 右栏 | w=400，左侧内边距 32px |
| 底栏 | x=32，y=408，w=736，h=48 |

阅读顺序：页面标题 → 20周 → 插画与尺寸说明 → 宝宝这周 → 妈妈这周 → 重要节点 → 底部入口。

## 6. 功能列表页布局

| 区域 | 位置与尺寸 |
| --- | --- |
| 顶栏 | x=32，y=24，w=736，h=72 |
| 功能网格 | x=32，y=112，w=736，h=312 |
| 网格列 | 2列，每列344px |
| 列间距 | 48px |
| 功能行 | 104px |
| 底部说明 | x=32，底边距=24px |

每个入口内部使用 `56px 编号区 + 自适应文字区 + 24px 箭头区`。整行作为触控区域，不在文字之间保留不可点击空隙。

## 7. 中文单语言实施边界

- 静态原型所有可见文案均为中文。
- 不设计语言切换入口或英文长度兼容布局。
- 第二阶段才移除现有业务代码中的英文枚举、文案映射、设置入口、持久化字段和相关测试。
- 当前阶段不接入真实字体资源，不修改底层显示驱动。
