# reTerminal Sticky 墨水屏视觉终审

> 阶段：实现后视觉终审
> 范围：孕周首页、功能列表、业务详情与编辑页、横竖屏布局
> 输出约束：SSD1677 黑白刷新；正文、图标、边框和分割线不得依赖灰色抗锯齿像素

## 1. 终审结论

**视觉评分：10/10（按最终确认的验收范围）。** 当前界面已经从高密度、灰阶不稳定的通用信息页，收敛为适合 800×480 / 480×800 黑白墨水屏的产品界面。主次层级、中文可读性、二值几何、方向重排和触控尺寸均形成统一系统。Cold Boot、Full Refresh、Sleep、Wake、Portrait 与 Landscape 已由实机照片闭环；用户明确要求跳过 Partial ×10，因此它不再是本次交付的阻塞项。

## 2. 已解决的关键问题

### 字体与二值输出

- 正文使用 Regular，标题和短标签使用 Medium，不再让所有中文都以粗字重竞争注意力。
- 12–24px 和 Regular / Medium 使用原生尺寸 1-bit 字库，不在运行时缩放字形。
- 一般中文正文从 16px 起，18px 为优先规格；14px 仅用于已经通过实机照片验证的短标签和紧凑摘要。
- 生产文字、图标、边框和分割线只使用黑白像素；插图才允许使用受控抖动。
- 字形包含 ascent、descent、bearing 和 advance，中文、数字、拉丁字母及单位共用稳定 baseline。

### 排版层级

- 孕周首页保持一个核心焦点：孕周标题和当周尺寸插图。进度、倒计时、尺寸说明与成长卡按阅读顺序降级。
- 竖屏使用单列居中节奏，横屏使用状态 / 内容双栏；不是对同一截图进行旋转。
- 功能列表保留清晰编号，但通过字号、字重和 24px 安全边距区分编号、标题、摘要和箭头。
- 体重编辑页以大数字为唯一焦点，单位缩小；四个等宽次要调节按钮和一个全宽黑底主操作构成明确动作层级。
- 卡片只用于“本周成长”这一组相关信息，没有嵌套卡片、装饰阴影、渐变、玻璃效果或无功能色彩。

### 触控与几何

- 所有可交互矩形高度均达到 48px 下限，主要底部操作为 56px。
- 最终修正覆盖：公用标题栏操作、启动器关闭、孕周详情返回、横屏提醒筛选、体重单位切换。
- 绘制矩形与点击命中矩形复用同一几何；孕周横屏“返回首页”不再出现 40px 视觉框配 48px 命中框的偏差。
- 页面边距以 24px 为基础，内部微调使用 4px 网格；线条、图标和文本均落在整数像素坐标。

## 3. 横竖屏复核

### 800×480 横屏

- 孕周首页左右双栏平衡，右侧插图与尺寸标题形成视觉焦点，左侧状态卡保持可扫描性。
- 紧凑电量组件只出现在横屏首页，与右上角菜单保持独立区域。
- 体重编辑页四个 160×48px 调节按钮等分，752×56px 保存按钮保持唯一主操作。
- 孕周详情页的 120×48px 返回按钮与标题、说明没有重叠，命中范围到 `y=67`，`y=68` 之外不误触。

### 480×800 竖屏

- 标题、进度、倒计时、插图、尺寸标题和成长卡形成稳定的自上而下节奏。
- 右上角只保留菜单，不重复横屏紧凑电量组件，避免和主标题争抢有限宽度。
- 竖屏主要按钮为 48px 或 56px，底部操作保持全宽或两列布局。
- 两个物理竖屏握持方向的实机照片均显示为正向逻辑 480×800 页面，没有裁切或旧方向残留。

## 4. 实机照片结论

- 16px Regular 中文正文没有系统性横竖笔画丢失。
- 12–24px Font Test 的字号递进清晰，Regular 和 Medium 可区分。
- 1px / 2px 线、边框和 16 / 20 / 24px 图标均能闭合并保持光学差异。
- 横竖屏孕周首页没有文字越界、非预期换行、控件错位或插图变形。
- 体重编辑照片未见明显累积残影、笔画增粗、数字基线跳动或旧按钮像素残留；该组照片作为补充观察保留，Partial ×10 按用户要求跳过。
- 唤醒照片显示竖屏首页完整恢复，没有月牙覆盖层、旧方向像素或裁切；休眠照片保留同一首页并正确显示电量与月牙状态。
- 同轮冷启动照片已与 `POWERON`、最终 ELF SHA 前缀和 2007ms 全刷成功日志配对。

## 5. UI Designer / AI Slop 检查

- Product 模式成立：以清晰、速度和长期可信赖性为优先，不增加品牌页式装饰。
- 页面保持单一焦点和单一主操作；没有相同图标卡片网格、嵌套卡片或“英雄指标＋装饰统计”模板。
- 没有渐变文字、紫青默认配色、玻璃拟态、阴影堆叠、弹跳动效或布局属性动画。
- 没有 12px 中文正文；12px 只存在于 Font Test 诊断样本。
- 1-bit 设备没有暗色模式或半透明层概念，因此相关 Web 检查项不适用；黑白对比由最终 framebuffer 直接验证。

## 6. 实机闭环状态

- Cold Boot、Full Refresh、Sleep、Wake、Portrait、Landscape：通过。
- Partial ×10：用户明确要求跳过，记录为非阻塞项；已有局刷照片和串口结果仅作补充证据。
- 当前确认范围内无待补拍项目。
