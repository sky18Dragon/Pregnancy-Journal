# Bebas Neue

`BebasNeue-Regular.otf` is the 2018 Dharma Type release, copied unmodified from
<https://github.com/dharmatype/Bebas-Neue> (`fonts/BebasNeue(2018)ByDhamraType/otf/`).
It is licensed under the SIL Open Font License 1.1; the license text is `OFL.txt` here.

Only the digits 0-9 are rasterised, by `tools/generate_pregnancy_plate_assets.py`, into the
1-bit week numerals in `src/ui/assets/pregnancy_plate_assets.cpp`. No font file ships in the firmware.
