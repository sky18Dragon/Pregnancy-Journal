## 容量与迁移说明

- 体重 366 条、胎动 42 会话；同日期体重更新保留 ID，满额不会自动覆盖。
- 索引最多 1,024 个 key，含 tombstone；不回收删除标记、日志或旧对象。
  首版全量 366 + 42 + 档案/偏好 4 + 旧提醒/产检 20 = 432，剩余 592 槽可留存
  删除标记或其他旧数据。槽位满时拒绝新增，不以“删除释放槽位”误导用户。
- 大恢复工作区一次分配在 PSRAM，约 205 KiB，以日志 `psram_bytes` 为准；
  实机运行栈/堆与长日志时延尚未验收。日志段为 256 KiB × 最多 99,999 段，
  介质容量与实际操作时延会先约束使用，不能宣传无限记录。
- 设置 → MicroSD → 原设备记录，分别选择通用来源与胎动。校验、稳定 ID 导入、
  逐条回读成功后才开放独立清除确认；冲突/损坏/换卡均需重新处理。
  通用清除保留 Reminder/Checkup/Kicks NVS；胎动清除仅针对 `kicks`。
- Kicks 没有单会话历史编辑/删除入口；到 42 会话后需规划备份的数据集。
  体重历史编辑保留原日期。新记录不回写 NVS，没有缺卡 Flash 降级。
