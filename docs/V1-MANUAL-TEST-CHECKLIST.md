## 4. 备份后执行：删除与换卡

仅使用已备份或可丢弃的数据卡。发生预期外数据丢失即记录失败，保留卡用于集中分析，不继续覆盖。

| ID | 操作 | 预期结果 | 结果/问题号 |
| --- | --- | --- | --- |
| D01 | 按备份流程安全取出，复制整个 PREGJNL；校验后在备用卡恢复完整同一数据集 | 校验通过，原档案/体重/胎动均可读；不手工混合两份目录 | |
| D02 | 空测试卡初始化：先取消，再重新确认创建 | 取消不创建；确认创建后无需重启即可设置档案、保存三类记录 | |
| D03 | 测试卡另放无关文件，点 DATASET 删除：先取消，再确认 | 取消不删；确认只删除 PREGJNL，无关文件保留；重新初始化可用 | |
| D04 | A/B 卡使用不同档案和记录，安全取出后交替插入 | 各自数据/偏好独立，不显示上一卡内容，不把 A 草稿保存到 B | |
| D05 | 在删除确认页换卡后尝试确认（开发人员配合，使用两张可丢弃卡） | 旧确认失效，不删除新卡数据；不把换卡错误当成功 | |
