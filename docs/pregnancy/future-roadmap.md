# Future roadmap

Recorded only; none of these capabilities is implemented or pre-wired in the
current offline product:

- Voice Memo
- Speech-to-Text
- AI Summary
- Wi-Fi Content Sync
- OTA
- Mobile Web Configuration
- Family Message
- Cloud Backup
- Partner App

Future work should preserve the current domain/HAL boundary and require an
explicit privacy and power review before adding networked features.
