# Future roadmap

The shipped scope is the six-app offline image documented in
[current-functionality.md](current-functionality.md). The items below are not
implemented or pre-wired.

- Voice Memo
- Speech-to-Text
- AI Summary
- Wi-Fi Content Sync
- OTA
- Mobile Web Configuration
- Family Message
- Cloud Backup
- Partner App

Future work should preserve the current domain/HAL boundary and require an
explicit privacy and power review before adding networked features.
