# 孕期手帐（Pregnancy Journal）

这是 Seeed Studio reTerminal Sticky 的精简固件框架，保留电子纸、触摸、按键、RTC、电量、IMU、蜂鸣器、共享总线和深度睡眠能力。

当前应用：孕周、产检、提醒、体重记录、数胎动和设置。六应用启动器采用适合 800×480 电子墨水屏的高对比黑白布局；设置页支持中英文切换、PCF8563 校时和电子纸清洁全刷。孕周支持预产期/末次月经与进度展示，提醒支持全局开关，体重与胎动数据均仅保存在设备本地。

体重应用支持 kg/lb 切换、同日覆盖、BMI、孕前基线增重与每周趋势提示；数胎动应用支持早/中/晚三时段计数、5 秒防重复点击、1 小时自动结束、12 小时估算和跨日变化提示。所有健康信息仅用于记录，不替代专业医疗判断。

## 已验证基线

硬件基线曾在 Seeed Studio reTerminal Sticky 实机完成构建、烧录和功能验证。当前改造已通过 20/20 项主机测试与 release 固件编译；新增功能仍需按硬件回归清单完成触控、局刷、休眠和唤醒验证。

当前 release 固件占用约 485 KB Flash、24 KB RAM，低于现有分区与内存预算。

构建与烧录命令、架构、迁移记录和硬件检查表见 [`README.md`](README.md) 与 [`docs/refactor`](docs/refactor)。
